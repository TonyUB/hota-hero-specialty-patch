# Repository data boundary

This repository is the public release portal. It contains distributable patches, public documentation, artwork, and the access-request entry point only.

Implementation notes, diagnostics, binary addresses, failure reports, internal tools, handoff documents, and full development history are maintained in owner-only private repositories. Do not submit secrets, access tokens, private repository URLs, or copied private material in an issue.

访问开发经验资料请使用“经验借阅申请”Issue 模板。授权由仓库所有者逐人审批，并可随时撤销。
