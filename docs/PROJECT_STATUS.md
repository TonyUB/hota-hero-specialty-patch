# 项目状态与接手结论

## 已确认事实

1. `Patch_v1.8` 是唯一可信的修改基线；v1.9、v2.0、v2.1、v2.2、v2.3 只能用于失败取证，不能继续开发或复用 Cure Hook。
2. 原始 `Patch_v1.8.zip` 的 SHA-256 与交接值一致，包内 12 个文件也全部逐项一致。
3. 当前补丁必须继续保留：
   - 埃尔芙槽位、25/25/25 仙灵初始兵力、仙灵/妖精伤害与速度各 +1；
   - 伊沃 12–24 半人马以及固定 6 + 6 木精灵；
   - 阿德拉原生祝福特长，并仅让阿德拉施放祝福时最终消耗为 0；
   - 梅洛迪娅、索姆拉、罗尼斯的 HotA 1.8.0 原生行为；
   - 215 帧 D32F `UN44.DEF` / `UN32.DEF` 及埃尔芙第 141 帧。
4. 过去失败的主要原因是把静态候选地址当作真实运行路径。HotA/HD DLL 或 patcher 很可能在运行时替换、覆盖或绕开磁盘 EXE 中的候选代码。

## 当前唯一功能目标：Stage 2

只处理仍有至少一个单位存活的兵队：

1. 保留原生 Cure 的治疗、解除负面状态和英雄特长缩放。
2. 先完成正常治疗。
3. 仅将实际剩余治疗量交给原生 Resurrection 路径。
4. 复活永久有效，且必须复用原生 Resurrection 的目标资格限制。
5. 不手工维护亡灵/元素/构装体黑名单，不手工写 `numberAlive`、`healthLost` 或 `numberForeverDead`。
6. 阿斯特拉的独立数据修改是初级智慧术 + 初级水系魔法。

Stage 2 不处理全灭尸体、不扩展高级水系群体 Cure 的尸体扫描，也不做相关 UI、AI 或提示。
