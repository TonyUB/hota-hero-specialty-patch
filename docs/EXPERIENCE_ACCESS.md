# 开发经验资料访问说明

本项目的补丁、使用说明、公开机制边界和版本摘要继续公开发布；详细技术路线、二进制地址、诊断记录、失败复盘、交接材料及内部维护经验存放在独立私有知识库中。

## 申请访问

需要借阅经验资料的开发者，请在本仓库提交 **“申请借阅开发经验 / Request experience access”** Issue，并说明 GitHub 用户名、用途、所需范围和项目性质。

申请将由仓库所有者人工审核。获准后，申请账号可被临时添加为私有知识库的只读协作者；资料不得转载、镜像、转交或用于商业行为。仓库所有者保留拒绝申请及随时撤销权限的权利。

## 所有者与 API 访问

仓库所有者可直接查看私有知识库，也可使用具备相应私有仓库权限的 GitHub API、GitHub CLI 或细粒度访问令牌读取资料。请勿把令牌、解密密钥或私有资料写入本公开仓库、补丁包或日志。

## 安全边界

- 不在公开仓库保存经验文件的明文或加密副本，避免旧 Git 历史和密钥管理造成泄露。
- 不在公开仓库保存私有知识库 URL、令牌、部署密钥或协作者名单。
- 公开仓库仅保留发布所需资料与申请入口。
- 私有知识库默认只授权仓库所有者；外部访问必须逐人审批，并遵循最小权限原则。
