## 3. V1.05 F7 NativePower 公式

```text
H = floor(((11L + 29) × (clamp(n, 1, 7) + 11)) / 12)
    + 5 × (P - 1)
    + 10 × max(0, clamp(w, 0, 3) - 1)
```

- `L=max(英雄等级,1)`。
- `P=max(当前有效力量,0)`。
- `n=clamp(目标生物等级,1,7)`。
- `w=clamp(水系魔法熟练度,0,3)`。
- 全部整数运算；主乘积除以 12 后向下取整，再加力量项和水系项。

已验证参考值：

| L | P | w | n=1..7 |
|---:|---:|---:|---|
| 1 | 1 | 1 | 40 / 43 / 46 / 50 / 53 / 56 / 60 |
| 5 | 1 | 1 | 84 / 91 / 98 / 105 / 112 / 119 / 126 |
| 2 | 4 | 2 | 76 / 80 / 84 / 88 / 93 / 97 / 101 |
| 5 | 4 | 3 | 119 / 126 / 133 / 140 / 147 / 154 / 161 |
| 10 | 5 | 1 | 159 / 170 / 182 / 193 / 205 / 216 / 228 |
| 20 | 10 | 3 | 314 / 334 / 355 / 376 / 397 / 417 / 438 |
| 30 | 25 | 3 | 499 / 528 / 558 / 588 / 618 / 648 / 678 |

附加不变量：力量每增加 1，`H` 固定增加 5；无/初级水系相同，中级比初级增加 10，高级比初级增加 20。

## 4. V1.05 实现位置与调用约定

### 实际治疗/复活总量

- 标准版与 HD 版 EXE：`VA 0x0065DE40`。
- 输入调用约定继承 V1.04：
  - `[ebp+0x08]`：战斗兵堆；`[stack+0x78]` 为 `0..6` 的兵种等级字段，先 `+1` 再限定为 `1..7`。
  - `[ebp+0x0C]`：当前有效力量 `P`。
  - `[ebp+0x10]`：英雄对象；`[hero+0x55]` 为英雄等级 `L`。
  - `[ebp+0x14]`：既有分发器计算好的水系附加值 `10×max(0,w-1)`。
- V1.05 只原位替换 80 字节 F6 计算区，不改变活体、尸体、群体扫描或日志调用路径。

### 英雄特长详情表

- 助手入口：标准版/HD 版 `VA 0x0065DF00`。
- `HotA.dll` 中两个既有指针已经在 V1.04 指向该入口，V1.05 不修改 DLL。
- 只对英雄 ID `25`（尤兰德）和 `170`（阿斯特拉）的治愈特长分流；其他英雄尾调用原版处理。
