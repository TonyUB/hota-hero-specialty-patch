## 中文摘要

V1.53 以正式 V1.52 为唯一父输入，将阿萨泽尔的初始部队调整为 20–30 小恶魔和 4–5 地狱猎犬。中间歌革兵种槽被关闭；现有弩车、补给车授予及全部战争机器机制保持不变。

安装时把 ZIP 内文件按原目录结构覆盖到独立的 HotA 1.8.0 测试副本。请勿将本包与其他修改同一文件的补丁混装。

## English Summary

V1.53 uses formal V1.52 as its sole parent. Azazel's starting troops are now limited to 20–30 Imps and 4–5 Hell Hounds. The middle Gog troop slot is disabled; the existing Ballista and Ammo Cart grants and all War Machine mechanics remain unchanged.

Extract the ZIP into a separate HotA 1.8.0 test copy while preserving its directory layout. Do not combine it with another patch that edits the same files.
