V1.53 以正式 V1.52 为唯一父输入，将阿萨泽尔的初始兵力调整为与原生弩车特英雄斐瑞一致：20–30 小恶魔、1 辆弩车、4–5 地狱猎犬。阿萨泽尔不再携带歌革；现有补给车授予及全部战争机器机制保持不变。

安装时把 ZIP 内文件按原目录结构覆盖到独立的 HotA 1.8.0 测试副本。请勿将本包与其他修改同一文件的补丁混装。

Extract the ZIP into a separate HotA 1.8.0 test copy while preserving its directory layout. Do not combine it with another patch that edits the same files.
