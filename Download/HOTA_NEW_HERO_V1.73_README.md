# HOTA_NEW_HERO_V1.73

V1.73 · 2026-11-25 · 适用 HotA 1.8.0 中文 HD 版

V1.73 加入塔楼英雄烬，并修正周一酒馆刷新姬嘉时重复获得寒冰之剑的问题。

V1.71 加入棱堡英雄姬嘉、寒冰之剑和凛冬裁决，并在「其它选项」中加入取消养步规则、经验翻倍、组合宝物只占一格及卷轴学习。详情见 https://github.com/TonyUB/hota-hero-specialty-patch/blob/main/docs/GLOBAL_OPTIONS.md 。

Close the game and extract the patch into the game root of Chinese HotA 1.8.0, preserving all folder names. Keep h3hota HD.exe, HD_HOTA.dll and centaur_probe.dll in the root. Launch h3hota HD.exe and start a new scenario to see Kija's starting setup.

V1.73 adds Ash, a Tower Alchemist, and fixes Kija receiving an extra Sword of Frost on the weekly tavern refresh.

V1.71 adds Kija, the Sword of Frost and Winter Judgment, plus four switches in Other Options. The options are local settings and are off by default on a fresh installation.
