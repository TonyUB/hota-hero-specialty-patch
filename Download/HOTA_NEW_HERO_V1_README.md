# HOTA_NEW_HERO_V1

适用于 HotA 1.8.0 中文版与 HD Mod。

## 英雄修改

- 埃尔芙：仙灵和妖精杀伤力 +1、速度 +1；初始兵力为 25 / 25 / 25 仙灵。
- 尤兰德、阿斯特拉：治愈魔法可以永久复活友方单位。施放疗伤时，英雄等级每增加(8-n)，效果提高10%，其中n是目标生物的等级。

## 安装

将 `HOTA_NEW_HERO_V1.zip` 解压至干净的 HotA 1.8.0 游戏根目录并覆盖同名文件。
