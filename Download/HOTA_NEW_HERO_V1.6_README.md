# HOTA_NEW_HERO_V1.6

发布日期：2026-10-20。适用 HotA 1.8.0 中文版，完整覆盖补丁，不含游戏本体。

本版在正式 V1.53 上整合瓦伦（人马特）和塔博克（九头特），保留全部既有正式英雄。
瓦伦支持基础半人马的首领／射手／斥候三选数量升级，费用为每只 20／30／20 金币，
金币和大小部队栏实时刷新；四种人马获得每级 10% 基础攻防与固定 +1 速度。
塔博克麾下大小九头获得钻地移动，分别额外反击一次／无限反击，并使用自定义破土动画。

关闭游戏后完整覆盖至 HotA 1.8.0 中文版根目录。保留全部子目录和根目录专属 DLL；
初始配置需新开局查看。不要再覆盖旧人马或九头测试包。
