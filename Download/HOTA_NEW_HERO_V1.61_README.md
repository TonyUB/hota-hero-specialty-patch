# HOTA_NEW_HERO_V1.61

HOTA_NEW_HERO_V1.61 正式版 — 2026-10-23
适用 HotA 1.8.0 中文版；完整覆盖补丁，不含游戏本体。

退出游戏，将本ZIP全部内容按目录结构覆盖到游戏根目录。保留Data、_HD3_Data目录层级；centaur_probe.dll须与游戏EXE放在同一目录。使用h3hota HD.exe启动。
初始携带物品与初始军队需新开局查看。旧存档已持有的弹药车不会被删除。

本版更新：
1. 人马特：半人马首领、斥候、射手互转。首领与斥候互转免费；转为射手每只补10金币；射手转首领或斥候免费、不退款。基础半人马升级方式不变，高级人马不能转回基础半人马。
2. 骨龙特：骷髅兵和骷髅勇士每60只兑换1只骨龙，自动计算最大数量；余下骷髅放入空部队栏。有余数且没有空位时提示部队已满，不结算。其他兵种比例不变。
3. 奥蕾加：挖掘前至少需要200点当前行动力，原奖励及成功后的行动力结算不变。
4. 战争机器特：取消初始弹药车，保留弩车。
5. 骨龙特说明使用用户指定原文；奥蕾加说明仅修改对应数字，其余游戏内文字不变。
