# HOTA_NEW_HERO_V1.51

正式发布日期：2026-08-22

## 安装

1. 准备 Heroes of Might and Magic III + Horn of the Abyss 1.8.0 中文环境。
2. 解压本包到游戏目录并允许覆盖同名文件。
3. 建议先备份原游戏目录；不要与来源不明或不同基线的 EXE/LOD 混用。

## V1.51 更新

- 奥蕾加大小头像更新为最终确认的 V7 构图；松散头像仍为标准 ZSoft PCX，且无可见调色板索引 0。
- 寻宝术概率调整为四等奖 80%、三等奖 15%、二等奖 4%、一等奖 1%。
- 四个奖池改为最终确认的显式名单，分别包含 44、32、40、17 件宝物，并正式纳入指定 HotA 新宝物。
- 非一等奖奖励提示追加当前保底进度（XX/100）。
- 保留同日结果稳定、第 20 次强制一等奖、移动后至少 100 行动力挖掘、方尖塔状态同步与金币即时刷新。

完整奖池名称与 ID 见 [`docs/SPECIAL_MECHANICS.md`](../docs/SPECIAL_MECHANICS.md#完整奖池)，机器可读名单见 [`HOTA_NEW_HERO_V1.51_manifest.json`](./HOTA_NEW_HERO_V1.51_manifest.json)。

## 继承内容

完整继承 V1.5 奥蕾加身份、初始技能、观天、宝箱图标和文本；完整继承 V1.4 阿萨泽尔战争机器系统以及更早正式版本的英雄机制。
