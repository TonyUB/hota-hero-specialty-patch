# HOTA_NEW_HERO_V1.5

正式发布日期：2026-08-22

## 安装

1. 准备 Heroes of Might and Magic III + Horn of the Abyss 1.8.0 中文环境。
2. 解压本包到游戏目录并允许覆盖同名文件。
3. 建议先备份原游戏目录；不要与来源不明或不同基线的 EXE/LOD 混用。

## V1.5 新增

- 奥蕾加（替换英雄 ID 110 奥力斯）：据点战斗法师。
- 初始技能：初级智慧术、初级侦察术。
- 初始魔法书实际掌握观天（spell ID 5）。
- 初始兵力：20–30 大耳怪、5–7 恶狼骑士、5–6 半兽人。
- 初始四维：攻击 2、防御 1、力量 1、知识 1。
- 特长：寻宝术。移动后仍可挖掘，但至少需要 100 点当前行动力。
- 每次成功挖掘同步一座未访问方尖塔信息，并从 70/15/10/5 四档奖池获得宝物与金币。
- 同一游戏日结果稳定；连续 19 次没有四级宝后，第 20 次强制尝试四级宝。
- 使用最终确认的据点风格大小头像与居中宝箱特长图标。
- 同版本热修已消除头像调色板索引 0 在额头和下颌形成的黑点，并补偿宝箱特长图标的实机水平镜像。

## 继承内容
