## 中文摘要

V1.53 以正式 V1.52 为唯一父版，并将用户确认不再崩溃的 TEST02 游戏文件逐字节正式化。阿萨泽尔正常初始军队为一队 4–5 地狱猎犬；撤退或战败后按原生最低军队规则返回酒馆时为一队 1 小恶魔。弩车、补给车和全部既有战争机器机制保持原路线。静态选将预览可能仍显示未修改的默认模板，以进入游戏后的实际军队为准。

守城战中被摧毁的急救帐篷和补给车不恢复；该行为按当前英雄特性保留。安装时把 ZIP 内文件按原目录结构覆盖到独立的 HotA 1.8.0 副本。请勿与其他修改同一文件的补丁混装。

## English Summary

V1.53 uses formal V1.52 as its sole parent and promotes every game member from the user-accepted, no-crash TEST02 candidate byte-for-byte. A normal new Azazel starts with one stack of 4–5 Hell Hounds. After defeat or retreat, the native minimum-army tavern return contains one Imp. Existing Ballista, Ammo Cart, and War Machine paths remain unchanged. The static pre-game preview may retain the unchanged inherited template; the in-game army is authoritative.

A First Aid Tent or Ammo Cart destroyed while defending a siege is not restored; this remains an accepted characteristic. Extract the ZIP into a separate HotA 1.8.0 copy while preserving its directory layout. Do not combine it with another patch that edits the same files.
