# 版本包保留与历史还原规则

生效日期：2026-08-18；最近更新：2026-08-24

## GitHub 文件保留范围

- `Download/` 只保留当前正式版 `HOTA_NEW_HERO_V1.52.zip` 及其 README、清单。
- `OLD/` 只保留当前版本更新前的一份正式基底 `HOTA_NEW_HERO_V1.51.zip` 及说明。
- 更早版本不继续占用当前下载目录；测试包、诊断包也不在公开仓库长期分发。

## 更老版本的还原方法

删除旧安装包不等于删除历史：每次正式修改必须在 `CHANGELOG/` 记录输入版本、修改内容、验收父节点、哈希与关键回滚边界；详细地址、构建器和失败经验保存在私人经验仓库。

```text
c0aa1a327bf13e2935b45d29beb1b82ff790a4d82d7b5a5860422b8a86b30d0a
```

V1.35 的原始发布树可由提交 `dbd5406` 取回。V1.4 正式包可由公开提交 `741a825` 所在发布树取回，SHA-256 为 `effc379e756bb5f41d56580fb329b54e2c122730effcea3a0189b7235216e9ba`。V1.5 可由 V1.51 的父发布树取回，SHA-256 为 `0e4694c051d6156bb0c9e8373fcdbf8cf56a5750202000c1dc0ab0d8e23965a0`。V1.51 当前作为唯一上一版保留在 `OLD/`，SHA-256 为 `40a25130a828194452367075618fb57ad4f3382ef78e104eb844233c14f9d5b5`。
