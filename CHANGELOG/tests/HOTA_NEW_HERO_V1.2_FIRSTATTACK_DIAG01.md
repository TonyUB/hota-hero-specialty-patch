# HOTA_NEW_HERO_V1.2_FIRSTATTACK_DIAG01

- 类型：行为透明的运行路径诊断包，不是正式版，也不是功能测试版。
- 来源：已验收正式版 `HOTA_NEW_HERO_V1.11.zip`。
- 目标：确认“每支友方部队第一次主动攻击必定触发幸运”所需的主动近战、主动远程、反击与同一攻击指令内重复判定入口。

## 本次做法

1. 保留 V1.11 `.luck3` 节前 `0x200` 字节及其中的固定幸运 `+3` 正式钩子。
2. 仅使用 `.luck3` 原有的全零预留空间，不扩展 EXE、不修改资源、DLL、英雄数据或战斗结果。
3. 在原生幸运投骰路径 `0x0043F648` 与 `0x0044152A` 写入可完全回滚的六字节跳转。
4. 只记录马洛迪亚（29）与黛瑞丝（43），输出 `hota_luck_firstdiag01.bin`。
5. 每条记录包含路径、调用者、攻击者、参数、英雄、阵营、队列、兵种、当前幸运以及关键战斗字段；不包含个人信息。

## 风险边界

- 诊断代码在原生投骰前保存全部通用寄存器和标志，写完日志后完整恢复，并重放被覆盖的 `mov eax,[esi+0x4EC]`。
- 厄运沙漏、诅咒之地等正式硬封锁仍在固定幸运钩子之前生效。
- 本包不得放入 `Download/`、`OLD/` 或 GitHub Release；诊断 ZIP 仅在本地 `build/` 中交付。

- 处理：DIAG01 停止继续测试，由 DIAG02 增加固定幸运路径加载证明，并移除攻击路径中的未证实类型解引用。
