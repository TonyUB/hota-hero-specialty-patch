# 2026-07-30 科洛尼斯学术特收尾修正测试 04

## 用户反馈

TEST03 已能正常进入游戏，学术交换功能、初始“减速”和说明文本均正常，但存在两个问题：

1. 特长图标显示为高级土系魔法，而不是高级学术；
2. 特长详情仍显示原屠戮的 `1-2级 +20 / 3-4级 +16 / 5-6级 +12 / 7级 +8`。

## 根因

### 图标

DEF 素材名使用从 1 开始的技能编号。学术的 EXE 辅助技能 ID 是 `18`，正确素材因此是第 59 帧：

- `Secskill.def`：`skill19c.pcx`；
- `SECSK32.def`：`skl3219c.pcx`。

TEST02/TEST03 使用的第 56 帧 `skill18c / skl3218c` 实际是高级土系魔法。

### 屠戮残留

两份正式 V1.14 EXE 的科洛尼斯原生特长表记录位于文件偏移 `0x002787E0`：

```text
03 00 00 00 37 00 00 00 00 ...
```

第一项 `3` 表示法术特长，第二项 `55` 表示屠戮。原生函数 `0x004E6260` 只有在记录类型等于 `3` 时才进入法术 ID 与加成计算。此前只改文本和初始魔法，没有修改这条分类记录。
