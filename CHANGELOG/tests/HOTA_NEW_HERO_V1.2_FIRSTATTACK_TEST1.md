- 用户回传 `hota_luck_firstdiag04.bin` 大小为 41,952 字节，SHA-256 为 `9e12342e54c468f01ba9ef60fadd12a3bd30045e41f00070b3e35a8119b430ab`。

## 功能边界

1. 战斗初始化 `0x00463B71` 清空 42 位逐队资格表和当前行动状态。
2. 原正式固定 `+3` 钩子仍位于原生硬封锁之后，但包装器改为只记录“原生幸运允许生效”的阵营，再回放原生幸运计算；不再固定返回 `3`。
3. 行动开始时，仅当所属阵营是马洛迪亚或黛瑞丝且原生硬封锁未命中，才消费该部队的首次资格。
4. HotA.dll 两条已证实回调仅在“当前回调攻击方 == 保存的主动部队”时写入 `isLucky=1`；原函数随后照常完成伤害、动画并在每次命中后清零。
5. 厄运沙漏、诅咒之地等原生提前返回不会抵达允许标记，因此仍可禁止首次幸运。
