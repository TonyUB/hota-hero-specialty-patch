# Patch_v2.5_STAGE3_TEST2 撤回说明

状态：**禁止继续安装；由 `Patch_v2.5_STAGE3_TEST3` 接替。**

本包可以正常启动，且以下项目已经实机通过：

- 尤兰德、阿斯特拉的高级水系群体治愈可以复活多个合法全灭兵队；
- 复活单位在战斗结束后永久保留；
- 亡灵不会复活死亡单位；
