## 目的

UIDIAG01 已确认正确安装，但实机施法/悬停后未生成文件。UIDIAG02 保留相同的正式 V1.05 来源、独立 `.uidiag` PE 节、原生序言跳板和文件记录器，只移除入口内的英雄 ID 与治愈术 ID 筛选。

现在每次进入原生通用法术效果计算函数 `0x004E59D0` 都会：

1. 通过 `0x006E7200` 跳板完整执行原生函数；
2. 保存原生 EAX 返回值；
3. 记录调用者、ECX 对象、`对象+0x1A` 原始 DWORD、三个原始参数及返回值；
4. 原样返回保存的 EAX。

诊断不依据参数含义修改调用，也不写入任何正式 V1.05 的治疗、复活、战斗日志、动画或音效状态。

## 记录格式

- 文件：`hota_cure_uidiag02.bin`
- 每条 40 字节，10 个小端 DWORD：
  1. `UID1` 魔数；
  2. 事件类型（1 = 第三个参数为空，2 = 非空）；
  3. 原生调用者返回地址；
  4. ECX 对象指针；
  5. `对象+0x1A` 原始 DWORD（对象为空则为 0）；
  6. 第一个栈参数；
  7. 第三个栈参数/目标指针；
  8. 第二个栈参数；
  9. 原生返回值；
  10. 保留字段。
