# HOTA_NEW_HERO_V1.5

发布日期：2026-08-22

## 新增

- 以奥蕾加替换据点英雄奥力斯（英雄 ID 110）。
- 新特长“寻宝术”：允许移动后挖掘，最低保留 100 点当前行动力。
- 每次成功挖掘同步一座未访问方尖塔信息，并发放分档宝物与金币。
- 奖励按游戏日确定，加入四级宝第 20 次强制尝试保底。
- 初始技能改为初级智慧术与初级侦察术，魔法书实际掌握观天。
- 更新最终据点风格头像与居中宝箱特长图标。

## 修正与验证

- 松散英雄头像统一输出为标准 ZSoft PCX，避免把 LOD 内部裸图像块直接作为 PCX 导致英雄选择界面崩溃。
- 两个 EXE 均完成英雄记录、特长类型、观天 spell ID 和三处行动力门槛的独立验证与 PE 校验和重算。
- 双语言 LOD、三份松散汉化覆盖、215 帧 UN32/UN44 图集隔离、ZIP CRC、回滚重建和确定性双构建全部通过。
