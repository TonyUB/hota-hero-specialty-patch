# HOTA_NEW_HERO_V1.04

## 版本定位

- 本版修正并完善既有治愈特长的数值实现、战斗日志与英雄特长详情，版本号按数值/机制完善规则增加 `0.01`。
- V1.03 的补丁和随包元数据从 `Download/` 移除；其哈希、结论与错误经验继续保留在版本日志和 Git 历史中。

## 正式修改

1. F6 Direct 数学公式保持不变：

   `H = floor((11L + 10P + 19) × (clamp(n,1,7) + 11) / 12) + 10 × max(0, clamp(w,0,3) - 1)`

   修正 V1.03 对战斗兵堆等级字段的倒置读取。`H3CreatureInformation.level` 为 `0–6`，正式实现使用 `n = clamp(level + 1, 1, 7)`；因此一级英雄、力量1、无/初级水系治疗1级兵固定为40。
2. 单体治愈在原版施法提示后记录目标的实际治疗量；群体治愈依次记录所有有效活体与尸体目标，之后再显示原版复活提示。
3. 治疗量使用完整本地化句式，例如：`泉水精灵获得104点治疗。`
4. `HotA.dat` 中阿斯特拉的结构化特长说明使用：`治愈术的治疗量随英雄等级和目标生物等级提升，并可永久复活己方阵亡单位。` HD 中文 loose HeroSpec 保留含义相同的简化说明，确保尤兰德界面不再回退到原版长公式文字。
5. 尤兰德和阿斯特拉的特长详情表改用同一 F6 公式。“效果”列显示实际治疗量 `H`；“奖励”列显示相对普通治愈术 `5P+30` 的整数增幅。
6. 阿斯特拉继续以初级智慧术和初级水系魔法开局。

## 门帘资料更新

- 三名英雄均在简介下方增加阵营：埃尔芙为元素城、尤兰德为壁垒、阿斯特拉为港口，并同步英文 Conflux、Rampart、Cove。
- 埃尔芙的初始技能修正为“初级战术 / 初级进攻术”。
- 创作方向统一润色：埃尔芙为“新兵种特长设计、战斗动画抓帧提取与全新英雄立绘创作”；两名治愈英雄为“原创魔法设计与新魔法机制开发”，英文信息同步更新。

## 保持不变

- 魔法书显示值及原版单体/群体施法范围。
- 永久复活资格、亡灵限制、尸体重叠与占格规则。
- 原版治愈动画与音效、复活起身动作、普通转世重生表现及原版复活提示。
- 埃尔芙、阿德拉和其他英雄的既有行为。

## 测试过程与经验

- LOG TEST1 证明单体日志入口正确，但暴露了群体缓存被清空、群体尸体绕过包装器，以及 V1.03 兵种等级倒置三个问题。
- LOG TEST2 修正上述问题，并通过单体、群体、活体、完整尸体、永久复活、逐队数值与日志顺序测试。
- UI TEST3 将简写日志改为完整句式，并接通 HotA.dat/HotA.dll 的实际特长详情路径。用户最终确认日志、说明、详情数值及全部功能均无问题。
- loose HeroSpec 只能覆盖普通英雄特长文本，不能替代 HotA.dat 中阿斯特拉的结构化说明；特长详情分级数据还需要单独修改 HotA.dll 的计算入口。

## 构建与验收

- 两个 EXE、HotA.dll、HotA.dat 的来源哈希、补丁上下文、机器码、代码洞、相对目标和完整回滚均通过。
- 两次独立正式构建生成完全相同的 ZIP；CRC、成员列表和逐文件 SHA-256 均通过。
- 标准版与 HD 版启动冒烟通过；用户实机确认单体/群体治愈、复活、逐队日志、说明与详情表全部通过。
- 正式版 EXE、HotA.dll 与 HotA.dat 的运行字节和通过验收的 UI TEST3 完全一致；仅随包正式说明和构建身份更新。
