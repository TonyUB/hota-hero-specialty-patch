# HOTA_NEW_HERO_V1.14：幸运英雄初始配置平衡调整

日期：2026-07-30

## 目标

在完整保留 V1.13 幸运与治愈机制的前提下，调整两名幸运特长英雄的初始配置：马洛迪亚改为初级智慧术 + 初级领导术，黛瑞丝的魔法书初始法术改为观天。

## 正式变更

1. 马洛迪亚的第一项技能仍为初级智慧术，第二项技能由初级神秘术改为初级领导术；魔法书与初始振奋不变。
2. 黛瑞丝仍为初级智慧术 + 初级智力，魔法书初始法术由魔法神箭改为观天（View Air）；魔法书标志不变。
3. 两名英雄的常驻幸运 `+3`、逐队每场首次主动攻击必定幸运、反击与同指令多段攻击边界、厄运沙漏和诅咒之地等原生硬封锁全部不变。
4. 埃尔芙、两名治愈英雄、阿德拉和其他未列明英雄的正式行为全部继承 V1.13。

## 二进制修改

两个 EXE 使用相同的英雄表布局：

- 英雄记录大小：`0x5C`
- 马洛迪亚英雄 ID：`29`
- 马洛迪亚记录文件偏移：`0x0027A83C`
- 马洛迪亚第二技能字段：`record + 0x14`，文件偏移 `0x0027A850`
- 原始值：`08 00 00 00`（神秘术）
- 修改值：`06 00 00 00`（领导术）
- 黛瑞丝英雄 ID：`43`
- 黛瑞丝记录文件偏移：`0x0027AD44`
- 黛瑞丝初始法术字段：`record + 0x20`，文件偏移 `0x0027AD64`
- 原始值：`0F 00 00 00`（魔法神箭）
- 修改值：`05 00 00 00`（观天 / View Air）

除上述两个字段与 PE 校验和外，两个 EXE 没有其他字节变化。回滚值分别为 `08 00 00 00` 与 `0F 00 00 00`。

## 文件边界

相对 V1.13，补丁包内仅以下文件改变：

- `h3hota.exe`
- `h3hota HD.exe`
- `安装说明.txt`

`HotA.dll`、`HotA.dat`、两份语言 LOD、中文 HeroSpec、HD DEF、埃尔芙资源及其他全部文件与 V1.13 逐字节一致。

## 验证结果

- 两次独立构建生成相同 ZIP 哈希。
- 独立验证器确认 ZIP CRC、成员集合和逐文件哈希一致。
- 两个 EXE 的完整来源记录、输出记录、允许变化字节和 PE 校验和有效。
- 恢复两个英雄字段和校验和后，可逐字节重建 V1.13 来源 EXE。
- 标准版与 HD 版启动门禁通过。

## 经验

这两项均属于 EXE 默认英雄记录中的静态配置，不需要新增运行时 Hook。技能类型和初始法术必须分别修改各自的 dword 字段，并同时校验完整英雄记录，避免误伤技能等级、魔法书标志、初始兵力或相邻英雄数据。
