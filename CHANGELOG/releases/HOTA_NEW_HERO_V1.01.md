# HOTA_NEW_HERO_V1.01

> **状态：已撤回，安装包不再保留。** 本版把用户指定的公式误解为“高级水系下的总治疗量”，又保留了原版水系熟练度的 `-20 / -10` 数值差，导致 `P=1、L=1` 时分别出现 20 / 30 / 40，而不是所有水系等级均为 40。该问题已由 V1.02 修正。此日志和原 ZIP 的 SHA-256 仅用于保留错误原因、回滚依据与开发经验。

## 版本规则

- 新英雄或新的英雄特长版本增加 `0.1`。
- 既有英雄的数值调整版本增加 `0.01`。
- 本次只调整尤兰德与阿斯特拉的治愈数值，因此版本号由 V1 增加为 V1.01。

## 修改内容

1. 尤兰德与阿斯特拉的高级水系治愈总量改为：

   `H = 10P + 30 + floor((20P + 60) × 3(L - 1) / (3L + 16 - n))`

   其中 `P` 为英雄力量，`L` 为英雄等级，`n` 为目标生物等级。正整数除法按游戏使用的整数方式向下取整。
2. 无水系/初级水系与中级水系继续保留原版相对高级水系的 `-20 / -10` 基础差值。等价的两名英雄专属加成为：

   `Δ = 5P + floor((20P + 60) × 3(L - 1) / (3L + 16 - n))`
3. 活体治疗、活体治疗溢出复活和全灭尸体复活统一调用上述专属加成，避免同一次群体治愈使用两套公式。
4. 两个中文 `HeroSpec.txt` 中删除旧的 `(8-n)` 公式说明，改为：

   `治愈术的效果随英雄等级和目标生物等级提升，并可永久复活己方阵亡单位。`
5. README 英文同步为：

   `Cure becomes more effective with the hero's level and the target creature's level, and can permanently resurrect fallen friendly units.`
6. 核对阿斯特拉：两个 EXE 在文件偏移 `0x0027D07C`（VA `0x0067D07C`）均保持 `01 00 00 00 / 07 00 00 00 / 10 00 00 00`，对应现有的“初级智慧术 + 初级水系魔法”，无需再次改写。

## 保持不变

- 治愈的解除负面状态、永久复活资格、亡灵限制、重叠/占格尸体规则。
- 单体和高级水系群体复活机制。
- 原版治愈动画与音效、逐队起身动作、转世重生圆圈/音效隔离。
- 战斗日志“先施放治愈、后显示复活”的顺序。
- 埃尔芙、阿德拉和其他英雄的现有效果。

## 验证与经验

- 两个 EXE 在写入前分别核验原生治愈特长调用上下文、原有尸体治疗计算器和空代码区。
- 普通英雄继续尾调用原版 `0x004E6260`；只有英雄 ID `0x19 / 0xAA` 使用新公式。
- 新代码同时被活体 `CureCore` 和尸体治疗计算器引用，并通过反汇编目标、PE 映射、完整回滚和双构建复现检查。
- 静态验证不能代替实机数值验证；首次安装后应至少核对一次单体治愈和一次高级水系群体治愈。
