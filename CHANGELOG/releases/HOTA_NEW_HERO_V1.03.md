# HOTA_NEW_HERO_V1.03

## 版本定位

- 本版调整现有治愈特长的数值公式与阿斯特拉的初始技能，版本号按规则增加 `0.01`。
- V1.02 的 ZIP 与随包元数据从 `Download/` 移除；其功能、哈希和经验继续保留在版本日志与 Git 历史中。

## 修改内容

1. 尤兰德与阿斯特拉统一采用交接包 F6 Direct：

   `H = floor((11L + 10P + 19) × (clamp(n,1,7) + 11) / 12) + 10 × max(0, clamp(w,0,3) - 1)`

   `H` 为最终治疗/复活生命值，`P` 为英雄力量，`L` 为英雄等级，`n` 为目标生物等级，`w` 为水系魔法熟练度（无/初级/中级/高级取 0/1/2/3）。目标等级限定为 1–7；主公式向下取整后，中级/高级水系再增加 10/20 点。
2. 原版水系魔法的单体/群体施法范围规则保持不变。活体治疗、治疗溢出复活与全灭尸体复活均使用同一最终总量。
3. `P=1、L=1`、无或初级水系时，1级兵治疗量为 40，7级兵为 60；中级/高级水系分别在取整结果上增加 10/20 点。
4. 在 `HotA.dat` 的 `Heroes\hero170.str` 中，把阿斯特拉第二项初始技能从初级幸运术改为初级水系魔法。初级智慧术、技能等级、魔法书和初始治愈术均保持不变。

## 保持不变

- 治愈特长简介继续使用简化文本：`治愈术的效果随英雄等级和目标生物等级提升，并可永久复活己方阵亡单位。`
- 永久复活资格、亡灵限制、重叠/占格尸体规则、单体与群体目标规则。
- 原版治愈动画与音效、逐队起身动作、转世重生圆圈/音效隔离和战斗日志顺序。
- 埃尔芙、阿德拉和其他英雄的现有行为。

## 静态验收

- 标准版与 HD 版 EXE 均通过新公式、阿德拉与埃尔芙不变量校验。
- `HotA.dat` 通过阿斯特拉“初级智慧术 + 初级水系魔法”、魔法书与治愈术不变量校验。
- 中英文 HeroSpec 档案通过简化治愈描述校验。
- 两次独立构建得到完全相同的 ZIP，且通过 CRC、成员列表和逐文件 SHA-256 校验。
- 新公式和初始技能尚需在新开地图中做一次实机确认；静态校验不替代运行测试。

## 错误修正与经验

- 上一轮曾依据 EXE 中相邻的技能 ID 推断阿斯特拉已有运行时覆盖，但没有找到该数据的实际读取路径；这种“相邻字节符合预期”不能证明归属或生效。本版改为补丁化结构明确的 `HotA.dat` 英雄记录，并同时校验路径、块长、完整技能字段和来源哈希。
- F6 Direct 的水系加成必须在主公式整数除法完成后再相加；如果先把加成并入乘法项，取整边界会产生不同结果。构建器与 README 均固定记录运算顺序，后续修改公式时必须同步更新两处。
- 旧存档可能保留英雄生成时的技能数据，因此初始技能验证必须使用新开地图或新生成的阿斯特拉。
