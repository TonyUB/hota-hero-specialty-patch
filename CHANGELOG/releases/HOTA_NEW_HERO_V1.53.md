# HOTA_NEW_HERO_V1.53

发布日期：2026-09-05

正式 SHA-256：`1628cf4addf40e3d0f569682ef8179c3d20d3bc1709a5498e42e3572fb7c950f`

本版以指定 SHA 的正式 V1.52 为唯一重建父版，把用户确认不再崩溃的 `HOTA_V152_AZAZEL_DOG_ONLY_TEST02` 全部 23 个游戏成员逐字节正式化。正常初始阿萨泽尔只有一队 `4–5` 地狱猎犬；最低军队请求继续走原生路径，因此撤退或战败后返回酒馆时只有一队 `1` 小恶魔。弩车和补给车仍由既有运行时路径授予。

相对 V1.52 只有两份 EXE 变化。新层在实际七格军队清空后分流 Hero63 的正常军队与最低军队请求，默认 Hero63 模板和三份 `HOTRAITS.TXT` 均未修改。静态选将预览可能仍保留旧显示。

TEST02 的确定性重建与候选逐字节一致，正式封装也通过双构建与 ZIP、成员、PE 和 Hook 验证。用户确认该节点不再崩溃，但完整 Standard / HD、撤退、战败、投降和重新招募实机矩阵尚未逐项证明。

守城战中被摧毁的急救帐篷和补给车仍不恢复；用户决定暂作为英雄特性保留。本版未重开 `.wm17`，也未把合成控制流模型记录为守城实测通过。守城弩车状态未确认，不从帐篷和补给车结果外推。
