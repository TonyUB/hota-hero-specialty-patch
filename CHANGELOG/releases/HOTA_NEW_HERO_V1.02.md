# HOTA_NEW_HERO_V1.02

## 版本定位

- 本版是 V1.01 的纠正版，仍属于现有英雄的数值调整，因此版本号增加 `0.01`。
- V1.01 安装包不再保留，只保留其 SHA-256、错误原因与经验日志。

## 修正内容

1. 尤兰德与阿斯特拉的最终治愈量在所有水系魔法熟练度下均直接使用：

   `H = 10P + 30 + floor((20P + 60) × 3(L - 1) / (3L + 16 - n))`

   其中 `P` 为英雄力量，`L` 为英雄等级，`n` 为目标生物等级。正整数除法按游戏的整数运算向下取整。
2. `P=1、L=1` 时，成长项为 0，因此无论目标兵种等级和水系熟练度，最终治疗量都固定为 `40`。
3. 水系魔法熟练度只沿用原版施法范围：非高级水系为单体治愈，高级水系为群体治愈；不再改变这两名英雄的治疗数值。
4. 活体治疗路径中，补丁先返回“公式总量减去原版已装载基础量”，再由原版 `CureCore` 加回基础量，最终严格得到 `H`。这是实现层抵消，不是另一套数值公式。
5. 全灭尸体复活路径直接返回 `H`，确保活体治疗、治疗溢出复活和尸体复活使用同一最终总量。

## 保持不变

- 英雄简介中的治愈特长文本保持：`治愈术的效果随英雄等级和目标生物等级提升，并可永久复活己方阵亡单位。`
- 阿斯特拉初始技能保持“初级智慧术 + 初级水系魔法”。
- 治愈的永久复活资格、亡灵限制、重叠/占格尸体规则、单体与群体目标规则。
- 原版治愈动画与音效、逐队起身动作、转世重生圆圈/音效隔离和战斗日志顺序。
- 埃尔芙、阿德拉和其他英雄的现有行为。

## V1.01 错误与经验

- 错误：把指定公式当成高级水系总量，并把原版水系基础值差异继续叠加到最终结果。
- 表现：`P=1、L=1` 时，无水系/初级、中级、高级分别为 20 / 30 / 40。
- 修正原则：设计公式定义的是“最终治疗总量”时，各运行路径必须归一到该总量；不能再把原版基础值当作设计结果的一部分。
- 静态检查只能确认公式、分支和字节一致；首次实机测试仍应分别核对一次单体治愈和高级水系群体治愈，确认两者同条件数值一致。

## 静态验收

- 两个 EXE 均核验 V1.01 公式区域后再替换，并记录原字节、补丁字节与回滚字节。
- 非特长英雄继续尾调用原版治愈特长函数。
- 阿斯特拉初始技能、阿德拉原版逻辑、埃尔芙伤害/速度逻辑和两个 HeroSpec 档案均保持不变。
- 两次独立构建的 ZIP SHA-256 必须一致，且通过 CRC、成员列表和逐文件哈希校验。
