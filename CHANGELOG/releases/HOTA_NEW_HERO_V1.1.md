# HOTA_NEW_HERO_V1.1：固定幸运特长

日期：2026-07-25
状态：正式发布；用户实机验收、独立静态验证、三次可复现构建与启动门禁通过

## 发布内容

1. 壁垒马洛迪亚（英雄 ID `29`）与塔楼黛瑞丝（英雄 ID `43`）所率部队的最终幸运值固定为 `+3`。
2. 普通正负幸运数值修正不能改变结果，包括负幸运事件、敌方兵种及宝物的数值影响。
3. 厄运沙漏、诅咒之地及同类“直接禁止幸运生效”的原生硬封锁仍然有效。
4. 马洛迪亚初始技能由初级智慧术 + 初级幸运术改为初级智慧术 + 初级神秘术；初始法术由幸运之神改为振奋。
5. 黛瑞丝的初级智慧术 + 初级智力保持不变；初始法术由幸运之神改为振奋。
6. 两人的幸运之神特长标签保留，详细说明更新为“英雄所率领部队的幸运值始终为+3。”
7. 全局幸运之神魔法、鹰眼术、其他英雄及 V1.06 的治愈、复活和界面功能保持不变。

## 诊断与运行路径

在加入功能修改前，`HOTA_NEW_HERO_V1.1_LUCKDIAG01` 对 `H3Hero::GetLuckBonus` 的入口和原生封锁后位置进行行为透明记录。用户回传文件包含 `720` 条完整记录：

- 函数入口 `stage 1`：`360` 条；
- 通过原生硬封锁后的 `stage 2`：`360` 条；
- 所有普通战斗入口均能和随后抵达 `0x004E39E8` 的记录配对。

功能 Hook 因此安装在 `0x004E39E8`，只在所有原生硬封锁检查通过后对英雄 ID `29/43` 返回 `3`。

原生边界：

- 己方厄运沙漏扫描：`0x004E3964`
- 敌方厄运沙漏扫描：`0x004E39A9`
- 原生封锁返回 0：`0x004E39DE`—`0x004E39E5`
- 功能 Hook：`0x004E39E8`

因此厄运沙漏命中时不会抵达固定幸运 Hook。
