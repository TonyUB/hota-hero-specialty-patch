# 阿斯特拉初始技能来源核查与治愈公式排版

## 本次范围

- 用户提供的 `HOTA_项目交接包_2026-07-21.zip` 仅作为只读参考，没有并入或替换本仓库的交接资料。
- 本次不改补丁 ZIP、不改变任何游戏数值，也不增加版本号。
- 调整门帘 README 的中英文排版，并记录阿斯特拉初始技能来源的核查结论。

## 交接包线索

交接包确认了两点：

1. 阿斯特拉的目标配置是“初级智慧术 + 初级水系魔法”。
2. Pro 阶段曾对梅洛迪娅实现过同类初始技能替换。

但交接包没有保存具体 TXT 文件名、打包脚本或精确偏移，而且其中“该改动尚未进入 Patch_v1.8”的结论已经与当前二进制证据不符，不能直接作为实现依据。

## 数据核查

1. 官方 HotA 文档列出的阿斯特拉原始初始技能是初级智慧术 + 初级幸运术：<https://h3hota.com/en/documentation>。
2. 干净 HotA 1.8.0 与 Patch_v1.8 的 `HotA.dat` 中，`Heroes\hero170.str` 均位于条目偏移 `0x5012`；其 92 字节数值块位于 `0x519B`，SHA-256 均为：

   `6ad3eb9acd993d8211aa791e8a6738438519e9dab82a7107b113e23b61f30abd`

3. 该数值块中的两组初始技能数据均为 `(7,1) / (9,1)`，对应初级智慧术 + 初级幸运术。说明当前补丁没有通过 `HotA.dat` 的 `hero170.str` 改写阿斯特拉技能。
4. Patch_v1.8 的两个 EXE 在文件偏移 `0x0027D07C` 附近均与干净版不同，其中包含相邻的技能 ID `7 / 16`；V1.02 继续继承同一段数据。结合实机显示的“初级智慧术 + 初级水系魔法”，当前有效修改来自 Pro 阶段留下的 EXE 数据覆盖。

## 结论与经验

- 当前游戏内显示正确，不需要为本次 README 更新重新生成补丁。
- `Heroes\hero170.str` 是 `HotA.dat` 内的结构化英雄记录，不是当前发布包中的松散 TXT。未来若要改成更清晰的数据源方案，可以研究把第二技能从幸运术 ID `9` 改为水系魔法 ID `16` 后重新封装 `HotA.dat`，但必须先证明加载优先级并移除或隔离现有 EXE 覆盖，不能同时保留两套来源。
- 旧日志把 `0x0027D07C` 的前三个整数直接称为完整“阿斯特拉初始技能记录”过于简化；现阶段只确认该区域参与现有覆盖，不应在缺少读取路径证明时扩展解释其他相邻字段。
