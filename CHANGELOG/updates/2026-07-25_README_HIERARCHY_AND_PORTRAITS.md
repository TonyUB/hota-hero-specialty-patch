# 2026-07-25 门帘层级与英雄头像更新

## 目标

让分组说明的视觉层级与“当前治疗量公式”一致，并为中英文英雄条目增加紧凑、直观的对应头像。

## 调整

- 将中文“额外说明”“创作方向”和英文 `Additional Note`、`Creative Direction` 统一改为三级标题，下方使用普通段落承载内容。
- 删除“几名英雄共用 / shared by both heroes”等冗余标签；说明放在对应英雄组末尾，其作用范围由版面位置直接表达。
- 在五名英雄名称下方加入 36 像素高的头像；中英文条目复用同一组本地 PNG 资源。
- 新增 `tools/convert_h3_pcx.py`，用于把标准 PCX 或 Heroes III 原始 PCX 资源稳定转换为 PNG。

## 头像来源

- 埃尔芙：现有 `Patch_v1.8` 基线中的自定义大头像。
- 马洛迪亚、黛瑞丝、尤兰德：从用户提供的纯净 HotA 1.8.0 游戏 `H3bitmap.lod` 中提取。
- 阿斯特拉：Heroes 3 Wiki 提供的同名 HotA 原始 58×64 游戏头像。

## 边界与结论

本次仅更新 GitHub 门帘、头像资源、转换工具和维护规范，不修改任何游戏内数据，也不重新打包 `HOTA_NEW_HERO_V1.11.zip`。以后新增或调整英雄时，应同步维护中英文头像，并让分组级说明继续使用与公式相同的三级标题层级。
