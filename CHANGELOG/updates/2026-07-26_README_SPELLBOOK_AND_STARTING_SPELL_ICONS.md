# 2026-07-26 门帘魔法书与初始法术图标更新

## 目标

让读者在英雄名称下方的一行图像中直接辨认英雄头像、特长、是否携带魔法书以及魔法书中的初始法术。

## 排版

- 英雄头像、特长图标、魔法书图标和初始法术图标统一显示为 `72` 像素高。
- 头像与特长图标之间使用四个不换行空格。
- 特长图标与魔法书之间使用十二个不换行空格，形成更明显的功能分组。
- 魔法书与初始法术图标之间使用四个不换行空格，与头像/特长间距一致。
- 中英文条目使用同一组本地资源，并通过 `alt` / `title` 标明魔法书和法术名称。

## 英雄与法术

- 埃尔芙：当前英雄记录不带魔法书，只有头像与特长图标，不添加误导性图像。
- 马洛迪亚：魔法书 + 振奋。
- 黛瑞丝：魔法书 + 魔法神箭。
- 尤兰德：魔法书 + 治愈。
- 阿斯特拉：魔法书 + 治愈。

## 资源来源

- 魔法书：纯净 HotA 1.8.0 `H3sprite.lod` 中 `Artifact.def` 的 `HrArt000.pcx`。
- 魔法神箭：`spells.def` 的 `Sp16MBlt.pcx`。
- 治愈：`spells.def` 的 `Sp38Cure.pcx`。
- 振奋：`spells.def` 的 `Sp50Mrth.pcx`。
- 新增 `tools/extract_h3_def_frame.py`，以可复现方式解码 Heroes III DEF 的 format 0/1 帧并输出带透明通道的 PNG。

## 边界

图标只用于 GitHub 门帘。V1.13 游戏包的图像资源没有改变；包内游戏数据变更仅为黛瑞丝初始法术字段。
