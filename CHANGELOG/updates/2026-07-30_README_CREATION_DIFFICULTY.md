# README 创作难度栏（2026-07-30）

## 更新内容

- 在中英文门帘的英雄信息中新增三级标题“创作难度 / Creation Difficulty”。
- 难度上限统一为三颗星：完整星使用黑色五角星 `★`，未使用星使用 `☆`，半星使用半黑半白五角星资源 `assets/ui/half-star.svg`。
- 埃尔芙：1.5 / 3。
- 克洛尼斯学术特：1 / 3。
- 马洛迪亚、黛瑞丝幸运特长组：共用 1.5 / 3。
- 尤兰德、阿斯特拉治愈特长组：共用 2.5 / 3。

## 排版规则

- 单独英雄的难度栏紧接初始技能之后。
- 幸运和治愈英雄分别在各自两名英雄信息之后只显示一次组级难度，不额外标注“共用”。
- 中英文星级、层级和顺序完全一致。

## 素材说明

半星使用本地 SVG 绘制：同一颗五角星左半部填充黑色、右半部填充白色，并保留黑色轮廓，避免依赖不同系统对冷门 Unicode 半星字符的字体支持。
