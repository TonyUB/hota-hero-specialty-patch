# 2026-07-25 门帘头像放大与特长图标更新

## 目标

提高英雄头像辨识度，并让读者在浏览资料时能够同时看到英雄及其对应的游戏内特长图标。

## 调整

- 五名英雄头像的 README 显示高度由 36 像素提高至 72 像素。
- 每个头像右侧以四个不换行空格分隔，加入 44×44 的对应特长图标；中文与英文条目使用完全相同的布局和资源。
- 图标均从当前正式 V1.11 包的 215 帧 D32F `UN44.DEF` 提取：埃尔芙为第 141 帧，马洛迪亚为第 29 帧，黛瑞丝为第 43 帧，尤兰德为第 25 帧，阿斯特拉为第 170 帧。
- 图标作为本地 PNG 保存在 `assets/specialties/`，避免 README 依赖外部图片链接。

## 边界与结论

本次仅调整 GitHub 门帘及其静态图片资源，不修改游戏文件，也不重新打包 `HOTA_NEW_HERO_V1.11.zip`。以后英雄资料更新应保持“72 像素头像 + 四个不换行空格 + 44 像素特长图标”的同排结构。
