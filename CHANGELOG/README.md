# 开发改动日志

本目录是仓库清理后保留的唯一历史变更入口。

- `releases/`：每个正式版本的功能、文件、校验值和替代关系。
- `tests/`：每轮诊断或测试的设计、结果、错误与经验总结。
- `updates/`：不改变补丁二进制文件的仓库页面、说明文档与发布结构调整记录。

仓库不再保存历史测试 ZIP、解压目录、失败二进制、原始运行日志或测试清单。今后每次正式修改或诊断尝试都必须先新增一个独立 Markdown 日志，再清理临时产物。
