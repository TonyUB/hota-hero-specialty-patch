# 公开版本摘要

当前正式版本为 **HOTA_NEW_HERO_V1.4**。

## 2026-08-18：V1.4 阿萨泽尔

- 新增阿萨泽尔，替换英雄 ID 63 的夏洛克斯。
- 实际职业改为地狱战士“大魔鬼”（ID 6），初始四维为 `2/2/1/1`。
- 初始技能为初级弹道术、初级炮术；无魔法书和初始法术。
- 使用确认版红色地狱头像与投石车特长图标。
- 新增完整战争机器体系；玩家规则见 [`docs/SPECIAL_MECHANICS.md`](../docs/SPECIAL_MECHANICS.md)。
- 正式 ZIP 的 21 个游戏成员与用户实机验收的 TEST17 逐字节一致，仅根目录安装说明正式化。

详细发布记录：[`HOTA_NEW_HERO_V1.4`](./releases/HOTA_NEW_HERO_V1.4.md)。

## 2026-08-13：历史矮人构建撤回

2026-08-12 曾以 V1.4 标签短暂发布的矮人特长尝试，会使飞龙特等非目标兵种特长在进入自动战斗时永久卡死，且不会生成崩溃报告。该失败构建已撤回。项目所有者随后将阿萨泽尔正式版指定为规范 V1.4；两者仅发生过标签冲突，当前 V1.4 不继承失败构建的任何二进制、Hook 或构建器。

版本包保留与历史还原规则见 [`VERSION_RETENTION_POLICY.md`](./VERSION_RETENTION_POLICY.md)。

详细二进制地址、试错记录、失败复盘、内部工具链和完整开发历史保存在私有经验仓库。需要借阅开发经验的人员，请提交“经验借阅申请”Issue。
