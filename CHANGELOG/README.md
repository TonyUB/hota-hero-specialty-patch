# 公开版本摘要

当前正式版本为 **HOTA_NEW_HERO_V1.35**。

## 2026-08-13：V1.4 撤回

V1.4 的矮人特长尝试会使飞龙特等非目标兵种特长在进入自动战斗时永久卡死，且不会生成崩溃报告。该版本现已撤回；正式下载和后续开发锚点均恢复为 V1.35，门帘不再展示该英雄。V1.4 仅作为失败记录保留，不应继续分发或安装。

- 尤兰德与阿斯特拉保留“治愈魔法永久复活友方单位”机制，治疗量采用 HotA 1.8.0 原生治愈特长数值。
- 破灭重塑、龙族参战限制、幸运特长、学术特长与埃尔芙兵种特长的公开效果和边界见仓库门帘及 [`docs/SPECIAL_MECHANICS.md`](../docs/SPECIAL_MECHANICS.md)。
- 详细二进制地址、试错记录、失败复盘、内部工具链和完整开发历史已迁入私有仓库。

需要借阅开发经验的人员，请提交“经验借阅申请”Issue。申请由仓库所有者人工审核，不会自动授权。
