# 公开版本摘要

当前正式版本为 **HOTA_NEW_HERO_V1.53**。

## 2026-09-05：V1.53 阿萨泽尔初始兵力调整

- 阿萨泽尔正常初始部队改为一队 4–5 地狱猎犬；撤退或战败后的原生最低军队返回为一队 1 小恶魔。
- 默认模板保持不动，弩车和补给车继续走既有授予路径；守城战中被摧毁的急救帐篷和补给车不恢复。
- 三份 `HOTRAITS.TXT` 与默认模板保持不变；相对 V1.52 仅两份 EXE 变化，其余 21 个游戏成员冻结。
- 正式包通过确定性重建、封装和结构验证；用户确认 TEST02 不再崩溃，完整 Standard / HD 与生命周期实机矩阵未作扩大声明。

详细发布记录：[`HOTA_NEW_HERO_V1.53`](./releases/HOTA_NEW_HERO_V1.53.md)。

## 2026-08-24：V1.52 双保底与圣杯整合

- 寻宝术扩展为四等奖 / 三等奖 / 二等奖 / 一等奖 / 特等奖 `59% / 25% / 10% / 5% / 1%`。
- 普通四档按原生宝物类型动态筛选，特等奖使用 17 项固定池，并保留地图禁用与明确排除规则。
- 新增第 13 次强制一等奖与第 29 次强制特等奖；结算提示同步显示小 / 大保底进度。
- 真正挖出原版圣杯时保留原生流程，并跳过当天方尖塔、奖励与保底结算；实际获得特等奖宝物时播放原生圣杯音效。
- 正式包通过交接包精确重构、独立验证、确定性双构建以及标准版 / HD 版启动门禁。

详细发布记录：[`HOTA_NEW_HERO_V1.52`](./releases/HOTA_NEW_HERO_V1.52.md)。

## 2026-08-22：V1.51 奥蕾加平衡更新

- 更新最终 V7 大小头像。
- 寻宝术概率调整为四等奖 / 三等奖 / 二等奖 / 一等奖 `80% / 15% / 4% / 1%`。
- 四个奖池改为最终显式名单，分别为 44 / 32 / 40 / 17 项，并纳入指定 HotA 新宝物。
- 非一等奖提示增加当前保底进度（XX/100）；第 20 次强制一等奖规则不变。
- 正式包通过独立验证、确定性双构建以及标准版/HD版启动门禁。

详细发布记录：[`HOTA_NEW_HERO_V1.51`](./releases/HOTA_NEW_HERO_V1.51.md)。

## 2026-08-22：V1.5 奥蕾加

- 新增奥蕾加并以寻宝术替换原生鹰眼术特长。
- 初级智慧术 + 初级侦察术，魔法书实际掌握观天。
- 允许移动后以至少 100 点行动力挖掘，同步未访问方尖塔信息并获得确定性每日奖励。
- 解决松散头像格式崩溃、索引 0 黑点与宝箱实机镜像问题。

详细发布记录：[`HOTA_NEW_HERO_V1.5`](./releases/HOTA_NEW_HERO_V1.5.md)。

## 2026-08-18：V1.4 阿萨泽尔

- 新增阿萨泽尔，替换英雄 ID 63 的夏洛克斯。
- 实际职业改为地狱战士“大魔鬼”（ID 6），初始四维为 `2/2/1/1`。
- 新增完整战争机器体系；玩家规则见 [`docs/SPECIAL_MECHANICS.md`](../docs/SPECIAL_MECHANICS.md)。

详细发布记录：[`HOTA_NEW_HERO_V1.4`](./releases/HOTA_NEW_HERO_V1.4.md)。

## 2026-08-13：历史矮人构建撤回

2026-08-12 曾以 V1.4 标签短暂发布的矮人特长尝试，会使飞龙特等非目标兵种特长在进入自动战斗时永久卡死，且不会生成崩溃报告。该失败构建已撤回。项目所有者随后将阿萨泽尔正式版指定为规范 V1.4；两者仅发生过标签冲突，当前版本不继承失败构建的任何二进制、Hook 或构建器。

版本包保留与历史还原规则见 [`VERSION_RETENTION_POLICY.md`](./VERSION_RETENTION_POLICY.md)。详细二进制地址、试错记录、失败复盘、内部工具链和完整开发历史保存在私有经验仓库。
