# 阿斯特拉初始技能数据定位

## V1.03 结论

- 当前正式包中的有效记录是 `HotA.dat` 内的 `Heroes\hero170.str`。
- 该记录的数字数据块长度为 `0x5C`，文件绝对偏移为 `0x519B`。
- 第二技能类型位于数据块 `+0x14`（文件绝对偏移 `0x51AF`）。
- V1.02 原值为 `09 00 00 00`（幸运术），V1.03 改为 `10 00 00 00`（水系魔法）。
- 第二技能等级位于数据块 `+0x18`，继续保持 `01 00 00 00`（初级）。
- 第一技能保持智慧术 ID `7`、初级等级 `1`；魔法书标志保持 `1`；初始法术保持治愈术 ID `37`。

## 构建约束

构建器先校验来源 `HotA.dat` 的 SHA-256、`hero170` 唯一路径、数字块长度和完整技能字节，再执行单字段替换；任一条件不符即停止。Manifest 同时记录来源、输出、补丁和回滚字节。交接资料中出现的历史编号 `177` 不用于当前包，因为实际可解析并承载阿斯特拉数据的是 `hero170`。

## 验证边界

双份独立构建、静态数据解析和逐文件哈希已经通过。游戏内英雄初始技能应以新开地图或新生成英雄测试，旧存档可能继续携带生成时写入的技能数据。
